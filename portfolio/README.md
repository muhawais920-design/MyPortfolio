# Muhammad Awais Sattar - Portfolio

A premium, animated personal portfolio built with HTML5, CSS3, and Vanilla JavaScript.

## Run in VS Code

1. Open the `portfolio` folder in VS Code.
2. Install the "Live Server" extension (by Ritwick Dey) if not already installed.
3. Right-click `index.html` and choose "Open with Live Server".
4. The site will open at http://127.0.0.1:5500.

## Features

- Animated preloader, custom cursor, particle canvas background
- Typing effect, scroll reveals, skill progress bars
- Project cards with 3D tilt and detail modals
- Responsive design, mobile menu
- Contact form with validation and mailto fallback
- prefers-reduced-motion support

## Notes

- No fake achievements, experience, or repository links are included.
- The contact form uses a mailto fallback because no backend/email service is connected.
- Replace `assets/Muhammad_Awais_Sattar_Resume.pdf` with your actual resume PDF.
